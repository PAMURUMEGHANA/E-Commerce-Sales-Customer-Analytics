# E-commerce Sales Analysis

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data using SQL and MySQL Workbench to identify sales trends, customer behavior, product performance, and regional insights.

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- SQL
- GitHub

## 📊 Analysis Performed

- Sales performance analysis
- Customer analysis
- Product performance analysis
- Regional sales analysis
- Order analysis
- Revenue and quantity analysis

## 🔍 SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- CASE
- JOIN
- Subqueries

## 🎯 Project Objective

To transform raw e-commerce sales data into meaningful business insights using SQL.
